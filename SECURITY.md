# Security policy

This repository follows the [account security policy](https://github.com/ryanduguid/.github/blob/main/SECURITY.md).

## Supported versions

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Use this repository's [private vulnerability-reporting form](https://github.com/ryanduguid/au-accounting-hotkeys/security/advisories/new), under **Security** then **Report a vulnerability**. Do not open a public issue or pull request for a suspected vulnerability.

If that feature is unavailable, email [ryan@duguid.com.au](mailto:ryan@duguid.com.au) with `SECURITY` in the subject line. Email is unencrypted: send only a description, reproduction steps using fabricated data, likely impact and any suggested mitigation. Wait for a private channel before sending anything sensitive.

Never include client, taxpayer, employee, payroll, access-token or other sensitive data.

As in the account policy, we will acknowledge a valid report within 7 days and coordinate the fix and disclosure timeline with the reporter.
